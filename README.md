**uniion** is a specialized prompt-based plugin (skill) designed to enable the AI ​​assistant "Milka" to interact with external services—such as the Telegram Bot API, VS Code, and custom developer APIs.

---

## 🚀 How does it work?

The plugin requires no complex code configuration on the user's end. It operates at the level of system prompts:
1. You install the plugin into Milka by providing a link to this repository.
2. Milka reads the instructions embedded within the plugin.
3. The neural network learns the required format for receiving your API keys directly via chat, as well as how to generate the correct requests for integration with Telegram or VS Code.

---
## 🛠 Installation

1. Copy the link to this repository: [repository](https://github.com/viktorhridin24-maker/uniion-milka/)
2. Paste it into the **Repository or folder URL** field in the Milki interface.
3. Click **Install skill**.
